# show the parents for the specified node(s) in the tree

show the parents for the specified node(s) in the tree

## Usage

``` r
# S4 method for class 'atctree'
parents(h, node, anc = 1)
```

## Arguments

- h:

  tree the node belongs to

- node:

  a node e.g. A01AX

- anc:

  level of ancestry (default 1). How many generations back or forward?

## Value

atctree object
